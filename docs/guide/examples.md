# See the compiled result

Each example has copyable source, a complete source ZIP, a PDF, and previews of every page. The ZIP contains the exact variant used to compile the preview and instructions for building it from its own project root.

- [Worked homework]({{ '/examples/homework-worked/' | relative_url }}), [worksheet]({{ '/examples/homework-worksheet/' | relative_url }}), and [compact handout]({{ '/examples/homework-compact/' | relative_url }}) share the same fragments.

- [Standalone assignment]({{ '/examples/homework-subfile/' | relative_url }}) and [standalone chapter]({{ '/examples/notes-subfile/' | relative_url }}) demonstrate the subfiles workflow.
